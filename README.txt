LIGA MANAGER – iPhone PWA

Die Anwendung läuft als Web-App und speichert die Daten lokal im Browser.

Auf dem iPhone:
1. Die Dateien auf einen Webserver/Hosting hochladen.
2. Die Seite in Safari öffnen.
3. Teilen -> Zum Home-Bildschirm.
4. Starten wie eine App.

Für einen öffentlichen Link kann z.B. ein beliebiger statischer Webhost verwendet werden.
